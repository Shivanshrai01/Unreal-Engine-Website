# Unreal Engine Motion Website

A highly immersive, single-page motion website featuring a cinematic, scroll-triggered frame animation. Built with HTML5 Canvas, GSAP, and Tailwind CSS, this project delivers a premium, modern user experience with smooth transitions and glassmorphism UI elements.

## ✨ Features

- **Scroll-Driven Animation:** A custom 240-frame image sequence powered by GSAP ScrollTrigger and HTML5 Canvas to create a seamless 3D-like scrolling experience.
- **Premium UI/UX:** Uses glassmorphism containers, neon accents, and smooth scroll navigation.
- **Fully Responsive:** Adapts to all screen sizes, automatically scaling the animation frames to cover the background while preserving aspect ratios.
- **Vercel Ready:** Includes a `vercel.json` for zero-configuration deployment on Vercel.

## 🛠️ Technology Stack

- **HTML5 & Vanilla JavaScript**
- **CSS:** Tailwind CSS (via CDN) & Custom Vanilla CSS
- **Animation:** GSAP (GreenSock Animation Platform) & ScrollTrigger
- **Typography:** Google Fonts (Orbitron, Inter) & Material Icons

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Shivanshrai01/Unreal-Engine-Website.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Unreal-Engine-Website
   ```
3. Start a local server. You can use tools like `npx http-server`, Python's `http.server`, or the Live Server extension in VS Code:
   ```bash
   # Using npx (Node.js)
   npx http-server -p 8080
   
   # Using Python
   python -m http.server 8080
   ```
4. Open your browser and navigate to `http://localhost:8080`.

## 🌍 Deployment

This project is fully configured for deployment on **Vercel**. 
Simply import the repository into your Vercel dashboard and deploy. No build commands or output directories are required since it is a static website.
